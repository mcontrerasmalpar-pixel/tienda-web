# 🛍️ Tienda Web

Página web de tienda online inspirada en [demingtaguchi.com](https://demingtaguchi.com/), construida con HTML, Tailwind CSS y JavaScript vanilla.

## ✨ Características

- Catálogo de productos con grid responsive
- Carrito de compras con sidebar deslizable
- Sección Hero, Nosotros y Contacto
- Diseño mobile-first con Tailwind CSS
- Sin dependencias de frameworks (HTML + JS puro)

## 🚀 Cómo usar

1. Clona el repositorio:
```bash
git clone https://github.com/mcontrerasmalpar-pixel/tienda-web.git
cd tienda-web
```

2. Abre `index.html` en tu navegador, o usa Live Server en VS Code.

## 📁 Estructura

```
tienda-web/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos personalizados
└── js/
    ├── products.js     # Base de datos de productos
    ├── cart.js         # Lógica del carrito
    └── app.js          # Inicialización
```
